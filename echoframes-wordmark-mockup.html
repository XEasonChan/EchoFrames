EchoFrames · wordmark explorations

Eight directions for the EchoFrames wordmark, paired with the project's etymology: Echo (faithful replay of the source) + Frames (deterministic per-frame Remotion render). Pick one (or hybrid two) and we'll lock the system around it. Type stack borrows from the Memdex aesthetic — Libre Baskerville (serif), Instrument Serif (italic accent), Inter (sans), JetBrains Mono (technical). Same brand family, different tone.

01 · Sans bicolor (Remotion-style)
EchoFrames
Cleanest, most direct. Same trick as the Remotion wordmark — weight contrast inside one word does all the work. Safest for HN headline + favicon resizing.
02 · Serif/sans hybrid (Memdex-aligned)
EchoFrames
"Echo" carries the warmth + reflection metaphor in serif; "Frames" carries the precision in sans. Reads as thoughtful tool not dev library.
03 · Italic accent (most "Memdex")
EchoFrames
Instrument Serif italic for "Echo" — same italic that lives in Memdex's hero. Most premium feel; weakest "developer tool" signal.
04 · Frame ticks (technical signal)
EchoFrames
Adds a 4-tick film/keyframe glyph that animates in HF Apple-style. Strongest "this is a frame-by-frame thing" signal. Logo can stand alone as just the ticks.
05 · Echo ghost (conceptual)
EchoFrames
"Echo" stamped 3× with falling opacity behind itself — the wordmark literally echoes. Strongest concept but harder to use small (favicon, OG image).
06 · Stacked lockup
echoFrames
Tagline-as-mark: "echo" as descriptor for "Frames". Works well for a docs-site nav header. Square-ish proportion = good for sticker / merch.
07 · Mark + word (favicon system)
EFEchoFrames
"EF" square as the standalone icon (favicon, npm avatar, GitHub org). The tiny play-tick in the corner ties to concept 04. Works at 16×16 and 1024×1024.
08 · Dark mode primary + dot
EchoFrames
Dark backgrounds (HN, GitHub README, social cards) often dominate impressions. The single blue dot is the "live / running" signal — same trope as Vercel + Linear.
